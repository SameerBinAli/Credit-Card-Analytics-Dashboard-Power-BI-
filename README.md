# 📊 Credit Card Analytics Dashboard (Power BI)

This project presents an interactive Power BI dashboard analyzing credit card transactions and customer data to identify revenue trends, spending behavior, and customer segmentation insights.

## 🔹 Project Overview

The project consists of two Power BI dashboards:

### 1️⃣ **Credit Card Transaction Report**
Analyzes transaction-level data to track revenue, interest earned, transaction volume, and card usage behavior.

### 2️⃣ **Credit Card Customer Report**
Focuses on customer demographics and their contribution to revenue across income groups, occupations, and regions.

## 🛠 Tools Used
- **Power BI Desktop**
- **Power Query** (Data Transformation)
- **DAX** (Data Analysis Expressions)
- **CSV Files** (Data Source)

## 📈 Key Insights

### 🔸 **Transaction Report**
- **Total Revenue and Interest Earned**
- **Quarterly Revenue & Transaction Trends**
- **Transaction Volume by Quarter**
- **Revenue by Card Category** (Silver, Blue, Gold, Platinum)
- **Revenue by Card Usage Type** (Swipe, Chip, Online)
- **Customer Acquisition Cost by Card Type**

### 🔸 **Customer Report**
- **Revenue by Gender and Age Group**
- **Revenue by Marital Status**
- **Revenue by Income Group**
- **Revenue by Customer Occupation**
- **Top 5 States by Revenue**
- **Revenue by Dependent Count**
